Standards and community work

The VRM format and its public specifications make portable humanoid avatars possible. SonaPin’s compatibility work is informed by the VRM specification and the broader open avatar ecosystem.

Documentation site

This site is hand-built static HTML and CSS. Its build step uses Bun plus Node-compatible standard-library file APIs. It loads no third-party fonts, analytics, advertising, or runtime scripts.
