Built on a generous ecosystem.

SonaPin uses Apple platform technologies and plans to use a small, pinned set of open-source code. Exact versions and license text will be published from the final resolved build.

Standards and community work

The VRM format and its public specifications make portable humanoid avatars possible. SonaPin’s compatibility work is informed by the VRM specification and the broader open avatar ecosystem.

Documentation site

This site is hand-built static HTML and CSS. Its build step uses Bun plus Node-compatible standard-library file APIs. It loads no third-party fonts, analytics, advertising, or runtime scripts.

Final release checklist

  • Pin every production package to a verified stable version.
  • Record its author, source, version, and complete required license notice.
  • Match this public page to the acknowledgments included inside the app.
  • Review model assets and demo content for redistribution permission.
