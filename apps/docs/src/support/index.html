Support draft · Pre-release

Keep your badge on track.

SonaPin has not shipped yet. These planned troubleshooting steps will be verified against the release build, and the final support contact will be added before App Store submission.

Need support today? There is no public app build yet. Follow development in the source repository or visit the MrDemonWolf website. A dedicated contact channel is still being finalized.

QR code will not scan

Enlarge the code, use the high-contrast option, raise screen brightness, and reduce glare. Keep the entire white quiet zone visible.

Avatar import shows warnings

Review the compatibility report before replacing your current avatar. Unsupported model features should appear as actionable warnings rather than a raw parser error.

Motion feels uncomfortable

Enable Reduce Motion in iOS or SonaPin settings and lower interaction sensitivity. The release build is planned to respect the system preference.

Badge settings changed

Use the accidental-edit lock before handing your phone to someone. Onboarding, camera, and local app data reset controls are planned for Settings.

Before reporting a problem

  1. Record the SonaPin version shown in Settings.
  2. Record your iPhone model and iOS version.
  3. Write the smallest sequence of steps that reproduces the problem.
  4. Note whether the built-in demo avatar has the same problem.
  5. Add a screenshot only if it does not expose personal information.

Protect private data

Do not post private QR payloads, contact links, local file paths, or an avatar file you do not have permission to redistribute. A compatibility report is safer than sharing the original model, but review it before posting.

Imported model rights

Only import and display a model you have permission to use. SonaPin may summarize embedded license metadata, but it cannot grant rights or determine whether your use is allowed.

Accessibility support

The release target includes VoiceOver labels, Dynamic Type, Reduce Motion behavior, high-contrast QR presentation, and usable touch targets. Please include the accessibility setting involved when reporting a problem.
